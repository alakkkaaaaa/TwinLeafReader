## 本次实现

- EPUB：解析包级与 spine 级 rendition 元数据，区分可重排和固定版式；移除短文本图片书启发式和正文 DOM 替换。
- EPUB：等待图片解码、字体和绘制帧；固定版式按原 viewport / SVG viewBox 等比适配；RTL 分页使用相反位移和定位方向。
- EPUB：纯 SVG spine 使用本地 HTML 容器加载；夜间模式不对图片、背景图和 SVG 图像使用反色滤镜，并关闭 WebView 算法暗化。
- PDF 批注：新增五种笔型、三档压力曲线、历史点、原始／平滑压力、倾斜角、方位角和时间采集。
- PDF 批注：标准触笔主／副键可映射；增加悬停聚焦和失焦状态清理；横竖屏工具栏统一放在顶部。
- PDF 导出：笔宽和透明度复用实时绘制规则，铅笔按压力调整透明度，毛笔单点按方向导出扁笔触。
- 存储：墨迹 JSON 写入版本 2，读取兼容版本 1；原子保存流程不变。
