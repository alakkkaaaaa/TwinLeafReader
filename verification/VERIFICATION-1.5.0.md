4. 原有 EPUB 打开、横屏翻页、保存进度、返回书架及重新打开恢复位置。

## 边界

- EPUB 竖屏按章节加载，章末继续上滑切章；不是全书无限长页面。首章、末章边界不循环。
- 横竖屏 EPUB 版面不同，以章节和相对进度衔接，并非字符级锚点。
- PDF 原页面的空白边缘会保留，不裁剪文字。
- 此次功能测试使用合成多页 PDF 与双章节 EPUB；未逐页检查所有用户书籍，也未在实体平板验证流畅度。
- 图标保持 1.4.0 图案，本次没有再次尝试图像生成或透明边缘处理。
