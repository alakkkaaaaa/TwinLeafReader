# 大肥鱼阅读（原双页书房 / TwinLeaf Reader）

面向 Android 平板的本地优先 PDF / EPUB 阅读器。横屏可自动选择单双页，竖屏可选择连续滚动或卡片翻页；云同步默认关闭并由用户逐本选择。

## 3.0.3 更新

- 针对 OPPO Pad 4 Pro 官方智能触控键盘反馈“方向键正常、触控板仍只能翻一次”，补齐 3.0.2 遗漏的触控板触摸分发路径；触控板可以以 SOURCE_MOUSE 来源发送 DOWN / MOVE / UP，而不是只有滚轮 ACTION_SCROLL。
- 在 Activity 的触摸和通用运动入口统一识别外部双指滚动。支持带分类的坐标滑动、像素滚动轴及历史样本；不把普通鼠标点击、触屏双指或新的捏合手势当作翻页。
- 手势从普通 DOWN 转为双指滚动时先取消子视图旧点击，避免其保留按下状态；接管后即使 UP / CANCEL 丢失分类、轴归零或坐标越界也会收尾。起点在工具栏外的手势不会中途转入阅读翻页。
- PDF / EPUB 翻页动画期间收到 UP / CANCEL 时仍释放触点，防止动画屏蔽终止事件后遗留状态；方向键行为保持 3.0.2 的设计。
- 141 项 JVM 测试通过；19 项 Android 专项测试最终通过，其中一项旧夹具补齐手势结束事件后单独复测。实际 PDF / EPUB 页面覆盖滚轮、鼠标来源的坐标滑动及像素滑动。
- 安装包 `大肥鱼阅读-3.0.3-debug.apk`，版本代码 33，与旧版同签名，可覆盖安装。尚未获取用户实体键盘的原始事件日志，最终兼容效果需用户实机确认，不能以模拟器通过替代。

## 2.8.0 更新

- 无限笔记与 PDF 批注使用分块历史笔迹缓存，仅实时绘制最近 24 笔与当前笔画；缓存按屏幕和缩放调整清晰度，避免高分辨率屏幕反复淘汰缓存。
- 原始矢量笔迹保持不变，旧笔迹仍支持局部擦除、保存、同步与导出。缓存不是把笔记永久拍平成图片。

- 校准入口与实机验收方法见 [STYLUS_CALIBRATION.md](STYLUS_CALIBRATION.md)。OPPO Pencil 的实际信号与改善程度仍需在实体平板上验证。

## 当前边界

- 不支持带 DRM 的 EPUB 或加密 PDF
- PDF 是固定版式；当书页长宽比与半个屏幕差异很大时仍会保留边缘留白，以避免裁字；未进行自动裁边或 OCR 重排
- EPUB 按章节分页，短章节或封面可能只有左页有内容；本次未实现跨章节拼满一个跨页
- EPUB 依赖书籍自身的 HTML/CSS 质量；复杂交互式 EPUB 会按安全的静态内容显示
- 当前版本支持页码快捷收藏，不做 OCR、文字批注、文字锚点书签或全文检索
