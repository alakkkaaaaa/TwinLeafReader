## 3.0.3 更新

- 针对 OPPO Pad 4 Pro 官方智能触控键盘反馈“方向键正常、触控板仍只能翻一次”，补齐 3.0.2 遗漏的触控板触摸分发路径；触控板可以以 SOURCE_MOUSE 来源发送 DOWN / MOVE / UP，而不是只有滚轮 ACTION_SCROLL。
- 在 Activity 的触摸和通用运动入口统一识别外部双指滚动。支持带分类的坐标滑动、像素滚动轴及历史样本；不把普通鼠标点击、触屏双指或新的捏合手势当作翻页。
- 手势从普通 DOWN 转为双指滚动时先取消子视图旧点击，避免其保留按下状态；接管后即使 UP / CANCEL 丢失分类、轴归零或坐标越界也会收尾。起点在工具栏外的手势不会中途转入阅读翻页。
- PDF / EPUB 翻页动画期间收到 UP / CANCEL 时仍释放触点，防止动画屏蔽终止事件后遗留状态；方向键行为保持 3.0.2 的设计。
- 141 项 JVM 测试通过；19 项 Android 专项测试最终通过，其中一项旧夹具补齐手势结束事件后单独复测。实际 PDF / EPUB 页面覆盖滚轮、鼠标来源的坐标滑动及像素滑动。
- 安装包 `大肥鱼阅读-3.0.3-debug.apk`，版本代码 33，与旧版同签名，可覆盖安装。尚未获取用户实体键盘的原始事件日志，最终兼容效果需用户实机确认，不能以模拟器通过替代。

## 3.0.2 更新

- 修复触控板滚动没有持续接入阅读翻页的问题：阅读区域统一处理滚轮式滚动和 Android 14 及以上的原生双指滚动，不依赖先双击或重新获取页面焦点。兼容 PDF / EPUB 的卡片、卷页及连续滚动模式。
- 新增硬件方向键和 Page Up / Page Down：分页阅读时左／上为上一页，右／下为下一页；连续阅读时上下小幅滚动、Page Up / Page Down 大幅滚动，PDF 左右跳相邻物理页，EPUB 左右按视口滚动并在边界切换章节。
- 滚动累计达到阈值才翻页，持续输入有间隔控制；动画忙碌期间的请求不排队，避免停止操作后连续补翻。修复关闭系统动画时卡片动画引用未清理的时序问题。
- 书本设置、目录、文字输入、PDF 书写与放大等场景暂停阅读翻页快捷输入；退出阅读和窗口失焦时清理输入状态。
- 141 项 JVM 测试通过；16 项 Android 专项测试最终通过（含一次修正测试界面等待条件后的单项复测），覆盖重复滚动、方向键、PDF / EPUB 实际阅读界面和笔迹边界。实体触控板的驱动事件与自然滚动方向仍需实机验收。
- 安装包 `大肥鱼阅读-3.0.2-debug.apk`，版本代码 32，与 3.0.1 同签名，可覆盖安装；详见 `verification/VERIFICATION-3.0.2.md`。

## 3.0.1 更新

- 参考用户提供的 ColorOS 便签 APK 的无缓冲事件分发、可复用输入缓冲及独立墨迹渲染思路，改进 PDF 与无限笔记的通用 Android 绘制链路；不复制专有代码或原生引擎。
- 落笔请求无缓冲分发；正在书写的笔画不再每帧复制列表。Paint/Path 复用，Android 10+ 硬件画布按 128 段缓存当前笔画，封存块不重复录制；软件画布/旧系统回退直接绘制，荧光笔保持完整路径，防止透明度接缝。
- 加入短距离临时笔尖预测，基础前瞻最多 8ms，总前瞻最多 12ms，屏幕位移上限为 12dp 与估算 3mm 的较小值。急转、反向、压力骤降、无效及过期采样不预测；预测点不加入原始笔迹，抬笔/取消/悬停后清除。
- PDF 与无限笔记统一使用屏幕空间 0.35px 的距离采样，保留真实压力、倾斜、方向、历史点及原有校准和收笔保护；既有矢量保存、局部擦除、美化、同步及导出格式不变。
- 136 项 JVM 测试及 13 项 Android 专项测试通过；5000 点长笔画测试确认追加点仅重录最多 128 段，并验证重复绘制不重录、跨笔清理、荧光笔显示、抬笔事件边界、历史缓存与重载。
- 安装包 `大肥鱼阅读-3.0.1-debug.apk`，版本代码 31，与 3.0.0 同签名。没有套用 OPPO 私有刷新码，也没有实测 Pencil 2 的端到端延迟；细节见 `OPPO_NOTES_REFERENCE.md` 和 `verification/VERIFICATION-3.0.1.md`。

## 3.0.0 更新

- PDF 与 EPUB 共用按书保存的阅读布局入口：竖屏可在连续下滑和单页卡片间切换；横屏可在自动、单页、双页间循环，切换后立即生效并保持实际页码／章节位置。
- PDF 自动布局按旋转后的物理页面比例分组：封面和横置页完整单页显示，连续竖页组成双页；单双页边界使用跟手卡片过渡，连续双页仍使用仿真卷页。
- 单页卡片加入 18% 位移／速度提交、边缘点击、回弹及相邻页面预渲染。PDF 页码、进度、跳转和批注坐标继续以原文件物理页为准。
- EPUB 普通流式章节在横屏自动双栏；固定版式、横向声明、禁止跨页或宽图主导章节自动使用整页卡片，避免强拆图片。
- EPUB 图片保持比例并使用 `object-fit: contain`，图片、picture、figure 与 SVG 尽量不跨页；遵从图片方向信息，深色模式明确不对图片／SVG 反色。
- 书架分类升级为稳定 ID 的自定义分类：支持新建、重命名、删除和排序，支持单本与批量分配；“未分类”不可删除，删除其他分类只会把书移入“未分类”。
- 旧版四个固定分类自动迁移；未知旧分类会保留为自定义分类，分类与系列文件夹彼此独立。
- `testDebugUnitTest` 共 132 项通过；在 3390×2400 Android 15 模拟器验证旧书架迁移、分类管理、EPUB 横竖屏切换、卡片滑动和 PDF 自动单双页。安装包 `大肥鱼阅读-3.0.0-debug.apk`，版本代码 30，同签名覆盖安装。
- 自定义分类和阅读布局偏好是本机设置，本版不随 OneDrive 同步；固定版式 EPUB 的极端 CSS／SVG 仍取决于书源质量，OPPO Pad 4 Pro 实机流畅度仍需用户验收。

## 2.9.0 更新

- OneDrive 支持可选上传 PDF / EPUB 原文件；每本书可设置为仅本地、进度与批注、含原书，无限笔记提供仅本地与同步笔记两档。
- 云端书库采用显式刷新和按需下载，新设备不会自动占满存储。取消选择或退出登录不会自动删除 OneDrive 应用目录中的既有文件。
- 原书以完整 SHA-256 命名和校验，大文件使用可恢复分块上传，下载写入临时文件并完成大小、哈希检查后才导入书架。
- 进度、PDF 批注和无限笔记改为内容寻址的不可变分片与每设备 v2 清单；相同分片复用，避免每次上传整份笔记。
- 多设备合并使用祖先链识别先后；并发分支保留本机和云端版本，由用户处理冲突。落盘笔迹通过精确快照 CAS 防止同步期间的新笔迹被覆盖。
- 同步增加账户隔离、清单 eTag 缓存、JSON 总量与嵌套限制、逐分片 SHA 校验、失败明细、取消传播、Wi-Fi/不计费网络后台任务。
- 继续使用 `Files.ReadWrite.AppFolder` 最小权限，令牌和上传会话排除在系统云备份之外；兼容只读迁移 2.7.0 旧快照。
- 安装包 `大肥鱼阅读-2.9.0-debug.apk`，版本代码 29，同签名覆盖安装。真实 OneDrive 上传需用户自行授权后验收。

## 2.8.0 更新

- PDF 批注与无限笔记加入历史笔迹分块缓存，最近 24 笔实时绘制，适配高分辨率视口；原始矢量保留，旧笔迹仍可局部擦除、同步和导出。
- 撤销由整页快照改为有预算的差量记录：最多 80 个操作，约 8 MiB 估算预算，避免历史数据不断复制。
- 笔设置增加设备级压力校准，实时查看压力及可用悬停距离，完成采样后可试写、保存、清除或重做；不可靠的数据不强行应用。
- 收笔加入设备、指针、手势时间和悬停边界处理，防止残留移动事件延续上一笔；校准后绕过旧的固定低压力过滤，保护轻写。
- 缓存首次创建、跨级缩放和大量擦除仍有重建开销；实体 OPPO Pencil 的信号与连笔改善需实机验收，详见 STYLUS_CALIBRATION.md。

## 2.7.0 更新

- 书架更多菜单新增 OneDrive 同步。功能默认关闭，只有用户配置 Client ID、完成 Microsoft 授权、打开总开关并逐本勾选后才会上传。
- 权限限定为 `Files.ReadWrite.AppFolder`，云端数据写入应用专属目录；PDF / EPUB 原文件、书架封面和文件夹结构均不上传。
- 阅读进度、PDF 批注、无限笔记提供独立开关。无限笔记支持跨设备恢复；外部书籍必须在目标设备本地导入相同文件后，才会通过内容指纹匹配。
- 每台设备维护独立 JSON 快照，避免两台设备同时覆盖同一个文件；进度、批注和笔记按各自更新时间独立选取较新版本。
- 回到书架时前台补同步，设置页也可立即同步。网络链路直接访问 Microsoft Graph，不依赖 OneDrive 客户端是否及时刷新。
- 使用 OAuth 2.0 设备代码流程，APK 不含客户端密钥；首版授权令牌存放于应用私有目录但不额外加密，离线同时编辑采用较新版本覆盖。
- 安装包 `大肥鱼阅读-2.7.0-debug.apk`，版本代码 27，同签名覆盖安装。注册与授权步骤见 `ONEDRIVE_SETUP.md`。

## 2.6.1 更新

- PDF 不再接纳 `ACTION_UP` 的末端坐标，避免部分触笔驱动在笔尖离屏后报告漂移点；PDF 和无限笔记会在提交前统一复核最后 60—90ms。
- 收笔过滤改用按模式调整的自适应压力阈值，并结合速度突增、转向和回跳判断；单纯的压力降低不会删除正常撇捺或持续轻写。
- 无限笔记接入与 PDF 共用的低压力尾点缓冲和末尾裁剪流程，解决此前只在 PDF 生效的问题。
- 直线候选先去除孤立尖峰并按约 3px 重采样，再使用 PCA/总最小二乘拟合；判定综合 RMS、95% 垂距、路径/弦长比和累计反向投影。
- 标准模式的最短直线边界由 72px 调整为约 48px；新增稳健、标准、灵敏三档，灵敏模式约 36px 起生效，仍排除明显折线、回钩、反向和闭合路径。
- 安装包 `大肥鱼阅读-2.6.1-debug.apk`，版本代码 26，同签名覆盖安装。

## 2.6.0 更新

- PDF 批注与无限笔记新增非破坏式自动美化，提供关闭、轻度、标准、强力四档；处理只发生在抬笔之后，不增加实时跟笔链路的运算负担。
- 完成异常尖刺过滤、等距离重采样、转角保护、多级轨迹平滑及压力平滑；保留首尾点，并降低对急转折和回钩的处理强度。
- 新增长直线自动识别与拉直。候选笔画需达到 72px，并同时满足路径/弦长比、最大垂距及反向回折限制；短笔画、折线、回钩和闭合趋势被排除。
- PDF 美化输出钳制在页面边界内且固定原始端点；无限笔记按照当前画布缩放换算屏幕长度，识别条件不受世界坐标单位影响。
- `InkStroke` 同时保存原始点与渲染点，并记录处理档位和是否自动拉直；局部擦除生成的新片段会清除不再对应的整笔原始数据，避免错误恢复。
- PDF 批注 JSON 与无限笔记 JSON 升级至 v3，继续接受旧版 v1/v2；美化档位和自动拉直开关按文档保存，只影响新笔迹。
- 安装包 `大肥鱼阅读-2.6.0-debug.apk`，版本代码 25，同签名覆盖安装。

## 2.5.1 更新

- 无限笔记纸张选择由三种扩展为六种：空白、横线、方格、点阵、工程纸和等距纸，使用底部面板展示实时缩略预览。
- 支持 16—80 世界单位间距、0—100% 线条深浅，以及暖白、纯白、护眼黄、浅灰、深色五种底色；滑杆在松手后才持久化，降低连续写盘与封面重绘开销。

- 笔记管理新增重命名入口，名称去除首尾空格、最长 80 个字符；重命名不改变笔迹数据、封面、分类、排序和文件夹位置。
- 保存“导出辅助线”偏好仅用于未来导出功能；2.5.1 仍不提供无限笔记导出，界面中已明确提示。
- 安装包 `大肥鱼阅读-2.5.1-debug.apk`，版本代码 24，同签名覆盖安装。

## 2.5.0 更新

- 新增书架原生 `NOTE` 文档类型。可在根书架或文件夹中新建无限笔记，并参与分类、筛选、拖动排序、文件夹管理、自定义封面和删除流程。

- 提供空白、横线、点阵背景；通过独立 AtomicFile 保存笔迹、背景和视口，保存后自动生成 360×500 书架预览封面。
- 删除本地笔记前显示不可恢复提示并清理笔记与预览文件。图片、文本框、套索和区域导出不属于本期实现。
- 安装包 `大肥鱼阅读-2.5.0-debug.apk`，版本代码 23，同签名覆盖安装。

## 2.4.0 更新

- 批注栏新增展开与紧凑两种状态：展开栏保留完整拟物笔具及参数，落笔或选择工具后自动收起为右上角胶囊；胶囊提供当前工具、撤销、重做与退出入口，并可一键重新展开。

- PDF 大纲使用实际文件页码（包括封面）。EPUB 可指定章节序号和章节内页码；跳到章首时页码填 1。切换字号、横竖屏后仍使用当前版式的页码数字，不同于快捷页的相对位置恢复；非章首条目可能需要重新编辑。
- 大纲编辑中的定位图标可填入当前阅读位置，勾号保存；点击大纲条目立即跳转。删除书架记录也清理该书大纲，不改动原书。
- 连续翻页复用已准备的跨页，不再每翻一页就重建当前 PDF 跨页或清空 EPUB 邻页；沿翻页方向预取两跨页，并保留一跨页用于返回。
- 横屏使用全分辨率不透明 RGB565 页面纹理，降低缓存内存占用；文字分辨率不变，但彩色渐变精度较 ARGB8888 低。竖屏不改动该纹理配置。
- 卷页仍使用 64×48 曲面网格；网格投影改为复用数组，减少每帧临时对象和重复计算，保留文字扭曲和正反面效果。
- 安装包：`大肥鱼阅读-1.7.0-debug.apk`，同包名、同签名，可覆盖安装。

## 1.6.0 更新

- PDF 阅读区增加绘制边界；顶部按钮独立合成并使用明确的日间／夜间对比色，防止正文覆盖工具栏。
- 点击顶部页码，输入数字后按箭头跳转。PDF 按文件实际页序（包含封面，从 1 开始），不是书页印刷页码；EPUB 按当前章节内页码。
- 输入页码后点“书签＋”图标即可保存快捷页。点顶部书签图标查看，点列表数字跳转，垃圾桶仅移除该快捷页。
- 快捷页按书独立保存、重复添加去重，重开应用后仍保留；从书架移除书籍时同时清除其快捷页。
- EPUB 快捷页显示“章节序号 · 页码”。横屏按单栏为一页，跳转后展示包含该页的双页；竖屏按一个阅读区高度计算一页。字号或横竖屏变化会重新分页，跨版式快捷跳转按章节相对位置近似恢复，不保证逐字对齐。
- PDF 保留跳转目标页（包括双页中的右页）；竖屏短末页也允许对齐顶部。
- 安装包：`大肥鱼阅读-1.6.0-debug.apk`。同包名、同签名覆盖安装，勿先卸载以免丢失本地记录。

## 当前已记录的通用边界

- 不支持带 DRM 的 EPUB 或加密 PDF
- PDF 是固定版式；当书页长宽比与半个屏幕差异很大时仍会保留边缘留白，以避免裁字；未进行自动裁边或 OCR 重排
- EPUB 按章节分页，短章节或封面可能只有左页有内容；本次未实现跨章节拼满一个跨页
- EPUB 依赖书籍自身的 HTML/CSS 质量；复杂交互式 EPUB 会按安全的静态内容显示
- 当前版本支持页码快捷收藏，不做 OCR、文字批注、文字锚点书签或全文检索

补充：PDF 手写批注自 2.0 提供，EPUB 不支持手写批注。2.0.2 支持在书写模式下直接双指缩放。软件侧触笔过滤不能代替设备驱动的掌压识别，OPPO 实体设备表现仍需实机确认。
